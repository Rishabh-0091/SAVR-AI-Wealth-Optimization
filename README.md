# SAVR – AI Wealth Optimization Platform

SAVR is a fintech prototype designed to help users optimize spending, saving, and investing decisions through data-driven insights.

## Features
- Investment Recommendations
- Portfolio Dashboard
- Savings Tracking
- Smart Shopping & Price Comparison
- Market Monitoring
- Data Visualization
- User Authentication

## Technologies Used
- HTML
- CSS
- JavaScript
- APIs
- Data Analytics Concepts

## Project Objective
To provide users with actionable financial insights and wealth optimization tools through an intuitive digital platform.
